# Architecture Decision Records

One file per durable decision, numbered sequentially. A decision that is later reversed is
superseded explicitly by a new ADR; the original is never edited except to update its status
line and add the superseding link.

Required sections: Status, Context, Decision, Alternatives considered, Consequences.
