What TraceShield is (approved 2026-09-06, canonical text in docs/ProductBrief.md):

  An open-source Python package that sanitizes LLM and agent telemetry inside the export
  path, before it reaches an observability platform. It detects and redacts secrets, PII and
  sensitive tool arguments, preserves trace structure so traces stay debuggable, and records
  an auditable decision for every redaction.

Settled decisions (do not re-open without a superseding ADR):

  - ADR 0001: Python library on PyPI as `traceshield`, Python 3.10-3.13, hatchling +
    hatch-vcs, uv, ruff/mypy --strict/pytest/hypothesis/bandit/pip-audit gate. Core has zero
    runtime dependencies; OpenTelemetry support is the `traceshield[otel]` extra.
  - ADR 0002: Apache-2.0, with NOTICE and a project-name statement.
  - ADR 0003: integrate as a `SanitizingSpanExporter` wrapping any OTel `SpanExporter`.
    A SpanProcessor cannot work: `ReadableSpan` is immutable at `on_end`.
  - ADR 0004: deterministic detection for v0.1 (regex pack + checksum verifiers + Shannon
    entropy + key-name heuristics). No ML or NER; Presidio stays a later optional extra.
  - ADR 0005: repository stays private until v0.1.0 is complete and green, then goes public
    and publishes 0.1.0 to PyPI via Trusted Publishing (OIDC, no API tokens). No placeholder
    release. `traceshield` was unclaimed on PyPI as of 2026-09-06.
