# TraceShield

TraceShield is the working name for this repository. Product requirements, architecture,
and implementation stack are intentionally not committed yet; those decisions will be
made after the project brief is agreed.

This initial local baseline contains repository governance only:

- personal Git and GitHub ownership rules;
- coding, testing, security, and documentation standards;
- pull-request and completion rules; and
- instructions shared by Codex, Claude, and Cursor.

When resuming work, start with [`prompt.txt`](prompt.txt). Then read
[`AGENTS.md`](AGENTS.md),
[`docs/CodingStandards.md`](docs/CodingStandards.md) and
[`docs/GitHubWorkflow.md`](docs/GitHubWorkflow.md) before making changes.
